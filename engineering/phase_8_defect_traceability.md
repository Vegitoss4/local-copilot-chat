# Phase 8 — Defect Traceability Matrix

This document tracks all security, reliability, durability, and operational defects identified during the Phase 8 audit, their technical root causes, remediation applied, and verifying test suites.

| ID | Category | Component | Description & Root Cause | Remediation Applied | Verifying Test Suite |
|---|---|---|---|---|---|
| **DEF-01** | **Packaging Leakage** | `.vscodeignore` | Internal audit reports, architectural specifications (`engineering/**`, `FINAL_PRODUCTION_READINESS_AUDIT.md`, `IMPLEMENTATION_STATUS.md`), and CI workflows (`.github/**`) were not excluded from `.vsix` packages, risking exposure of internal audit reports in production extension binaries. | Added explicit exclusion rules in `.vscodeignore` (`engineering/**`, `.github/**`, `*.md`, `!README.md`, `!CHANGELOG.md`). | `npm run vscode:prepublish` & packaging verification |
| **DEF-02** | **Duplicate Module Hazard** | `src/extension.ts` | `src/configurationService.ts` was an uncommitted 1-line re-export bridge shadowing `src/services/configurationService.ts`. Direct imports risked circular reference or split singleton state. | Updated `src/extension.ts` to import directly from `./services/configurationService`. Preserved legacy bridge file untouched pending user deletion authorization. | `npm run compile`, `test/unit/configuration.test.ts` |
| **DEF-03** | **Transaction Crash Window** | `src/services/codeGenerationEngine.ts` | Multi-file transactional patches maintained rollback history only in transient Node process memory (`Map<string, string>`). If VS Code crashed mid-transaction, files remained in inconsistent state. | Implemented persistent on-disk write-ahead journal (`.vscode/local-copilot/tx-journal.json`) via `AtomicFileWriter`. Added `recoverInterruptedTransaction()` to auto-rollback partial writes on next extension activation. | `test/unit/codeGenerationEngine.test.ts` (3 tests) |
| **DEF-04** | **Unsaved Editor Clobbering** | `src/services/codeGenerationEngine.ts` | Code generation engine applied disk writes without checking if the target file had unsaved in-memory edits (`doc.isDirty`), causing silent data loss of developer edits. | Added dirty buffer detection guard: refuses transaction and requests user save before automated modification. | `test/unit/codeGenerationEngine.test.ts` |
| **DEF-05** | **Line Ending & BOM Mangling** | `src/services/codeGenerationEngine.ts` | Applying patches to CRLF or UTF-8 with BOM (`\uFEFF`) files stripped BOM and forced LF line endings, causing large spurious diffs. | Implemented CRLF/LF line ending normalization and UTF-8 BOM detection & preservation in `CodeGenerationEngine`. | `test/unit/codeGenerationEngine.test.ts` |
| **DEF-06** | **Mid-Transaction Concurrency Race** | `src/services/codeGenerationEngine.ts` | External edits to files between transaction calculation and commit could result in overwriting foreign changes. | Implemented two-phase SHA-256 pre-image hashing before applying modifications or deletions. Fails closed if file content changed. | `test/unit/codeGenerationEngine.test.ts` |
| **DEF-07** | **Prompt Injection Target Weaponization** | `src/services/pathSecurity.ts`, `autonomousAgent.ts` | Autonomous mode permitted LLMs to autonomously modify sensitive files (`.git/hooks/**`, `.github/workflows/**`, `package.json`, `.env*`, `*.sh`, `*.bat`) without developer confirmation. | Implemented `PathSecurity.isSensitiveTarget()`. Enforced mandatory host-side developer modal confirmation for sensitive targets and file batches > 10 files even in autonomous mode. Refused `/fix` autonomous modifications to sensitive targets. | `test/unit/toolSafety.test.ts`, `THREAT_MODEL.md` |
| **DEF-08** | **Lack of Real OS Verification** | `test/` | Baseline tests relied 100% on mocked environments (`vscodeMock`, in-memory `mockFs`, mocked `fetch`). Real process execution, Git hooks, junctions, sockets, and disk writes were unverified against the real OS. | Created dedicated `test/real-integration/` tier running real Node child processes, real Git CLI, real NTFS junctions/symlinks, real HTTP socket servers, and real disk atomic writes. | `test/real-integration/*.test.ts` (22 tests across 6 suites) |
| **DEF-09** | **Multi-Client VRAM Disruption** | `src/services/modelLifecycleManager.ts` | `switchModel` with `aggressiveUnload: true` bypassed model ownership checks, evicting third-party models loaded by external tools (e.g. Open WebUI, Continue) from GPU VRAM. | Constrained eviction in `switchModel`: only models registered in `_extensionOwnedModels` are unloaded unless `forceUnloadUnknown: true` is explicitly provided. | `test/real-integration/fakeOllamaServer.test.ts` |
| **DEF-10** | **Loss of Model Ownership on Reload** | `src/services/modelLifecycleManager.ts` | `_extensionOwnedModels` was stored in memory. Reloading VS Code window lost tracking of loaded models, preventing proper lifecycle management. | Integrated `MementoLike` (`context.workspaceState`) persistence for `_extensionOwnedModels`. Restores ownership state on extension activation. | `test/real-integration/fakeOllamaServer.test.ts`, `src/extension.ts` |
| **DEF-11** | **Opaque VRAM OOM Errors** | `src/services/ollamaService.ts` | When Ollama failed to allocate VRAM on 8 GB GPU hardware, generic HTTP 500 errors were returned without actionable remediation guidance. | Created `OllamaVramError` and `isVramAllocationError()`, detecting CUDA/memory allocation failures and providing actionable guidance on 8 GB VRAM budget (adjust `num_ctx`, choose smaller quantized models). | `test/real-integration/fakeOllamaServer.test.ts` |
| **DEF-12** | **Secret & Credential Logging Exposure** | `src/providers/chatViewProvider.ts` | Logging statements printed raw URLs, headers, and payloads to VS Code output channel and developer console, risking leakage of API keys and Bearer tokens. | Created `ExtensionLogger` with secret redaction engine (masking Bearer tokens, OpenAI/GitHub/AWS keys, password/secret assignments). Routed `ChatViewProvider._log` through `ExtensionLogger.redact()`. | `test/unit/extensionLogger.test.ts` |
| **DEF-13** | **AST Extraction Blind Spots** | `src/services/repositoryIntelligenceService.ts` | AST indexing only parsed static `import ... from ...` statements, missing dynamic `import(...)` calls and `export * from ...` / `export { x } from ...` re-exports, degrading dependency graph accuracy in modular codebases. | Added TypeScript AST visitors for `ts.isExportDeclaration` with `moduleSpecifier` and `ts.isCallExpression` with `SyntaxKind.ImportKeyword`. | `test/unit/repositoryIntelligence.test.ts` |
| **DEF-14** | **Benchmark Isolation & Determinism Gap** | `src/services/evaluationService.ts` | Benchmark suite lacked support for deterministic repetition across runs and structured multi-seed metrics. | Added `RunSuiteOptions` (`repetitions`, `isolateWorkspace`), computing average latency and verifying consistent pass rates across N runs. | `test/unit/evaluationBenchmark.test.ts` |
| **DEF-15 (SEC-01)** | **Sensitive Target Bypass in Swarm** | `src/services/swarmOrchestrator.ts` | In multi-agent mode (`SwarmOrchestrator`), `dispatchBaseTool` lacked `PathSecurity.isSensitiveTarget` and the 10-file batch cap, allowing sub-agents to modify `.git/**`, `.github/**`, CI configs, and shell scripts without approval in autonomous mode. | Added `touchesSensitiveTarget` and batch hard-cap checks in `SwarmOrchestrator.dispatchBaseTool`, enforcing mandatory modal confirmation in parity with `AutonomousAgent`. | `test/unit/toolSafety.test.ts` |
| **DEF-16 (SEC-02)** | **Secret Redaction Value Inversion** | `src/services/extensionLogger.ts` | `match.replace(captured, '[REDACTED]')` replaced the first occurrence of `captured` in `match`. If the secret value appeared in the key prefix (e.g. `secret: "secret_123"`), it replaced the key name and leaked the secret value. | Replaced using rightmost offset boundary (`match.lastIndexOf(captured)` and slicing) to ensure the secret value is replaced while preserving the key. | `test/unit/extensionLogger.test.ts` |
| **DEF-17 (CONC-01)** | **Mutex Queue Poisoning** | `src/services/atomicFileWriter.ts` | A single rejected write promise in `_writeQueues` permanently wedged subsequent writes to the same URI because `.then()` skipped execution on rejected promises. | Guarded queue chains with `(currentQueue || Promise.resolve()).catch(() => {})`, ensuring failed writes report errors to their caller without poisoning the queue. | `test/unit/atomicFileWriter.test.ts` |
| **DEF-18 (SEC-03)** | **Positional Git Subcommand Injection** | `src/services/gitExecutionIsolator.ts` | Non-positional check for `'diff'` injected `--no-ext-diff` and `--no-textconv` into commands where `diff` was a branch or argument name (e.g. `git checkout diff`). | Scoped `--no-ext-diff` injection strictly to the primary subcommand (`args[0] === 'diff'`). | `test/real-integration/gitIsolation.test.ts` |
| **DEF-19 (SEC-04)** | **Canonical Path Loss** | `src/services/pathSecurity.ts` | `ValidatedPath.canonicalFsPath` returned `candidateFsPath` (lexical path) instead of `canonicalTarget` (physical canonical target from `fs.realpathSync`). | Set `resolvedCanonicalFsPath = canonicalTarget` when target file exists on disk. | `src/services/pathSecurity.ts`, `test/real-integration/pathSecurityReal.test.ts` |
| **DEF-20 (CONC-02)** | **False Conflict Detection** | `src/services/codeGenerationEngine.ts` | Sequential multi-step modifications to the same file in a single transaction batch failed because step 2 verified against `snap.initialHash` instead of the newly written hash. | Verified against `snap.lastWrittenHash || snap.initialHash`. | `test/unit/codeGenerationEngine.test.ts` |
| **DEF-21 (CONC-03)** | **Unscoped Eviction in unloadCurrentModel** | `src/services/modelLifecycleManager.ts` | If `_lastActiveModel` was unset, `unloadCurrentModel` iterated through all resident models in Ollama and unloaded them without checking extension ownership. | Restricted eviction strictly to `this._extensionOwnedModels.has(name)`. | `src/services/modelLifecycleManager.ts`, `test/real-integration/fakeOllamaServer.test.ts` |
| **DEF-22 (CONC-04)** | **Premature Slash Command Model Unload** | `src/providers/chatViewProvider.ts` | Slash commands returning early before `notifyGenerationStart` still called `notifyGenerationEnd` in `finally`, causing premature model unloading if policy was `unloadImmediately`. | Added `modelTurnStarted` boolean guard; `notifyGenerationEnd` is only called if a model turn actually began. | `src/providers/chatViewProvider.ts` |
| **DEF-23 (RES-01)** | **Idle Timer Unhandled Rejection** | `src/services/modelLifecycleManager.ts` | The idle unload timer executed without `_enqueueOperation` mutex serialization and without `try/catch`, leaking unhandled rejections if Ollama was stopped while idle. | Wrapped idle unload in `_enqueueOperation` and `try/catch`. | `src/services/modelLifecycleManager.ts` |
| **DEF-24 (DOC-01)** | **Threat Model curl Classification** | `THREAT_MODEL.md` | Threat model stated `curl` is classified into Tier 3, whereas `CommandClassifier` implements it strictly as Tier 4 Prohibited. | Corrected `THREAT_MODEL.md` to document Tier 4 outright blocking of network downloaders. | `THREAT_MODEL.md` |
